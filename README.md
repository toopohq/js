# js

The JavaScript catalogue of Toopo: utility functions you copy into your project. One file per
function, zero dependencies, and the source lands in your repository as yours.

Each function lives in `functions/<domain>/<name>/`, is addressed as `js/<domain>/<name>`, and
carries its specification beside it. A function is written only under a name claimed in
[`toopohq/spec`](https://github.com/toopohq/spec). Delivered code targets Baseline Widely
Available.

This repository is MIT. A delivered file is MIT-0: no attribution owed.
